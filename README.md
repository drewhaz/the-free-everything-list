# The Free Everything List

The Free Everything List is a web app that organizes hundreds of free tools, apps, and online resources into one searchable and easy-to-browse collection.

## Features

* Search for resources
* Browse resources by category
* Explore free tools for education, productivity, AI, coding, design, finance, careers, entertainment, and more
* Simple, responsive interface

## Built With

* HTML
* CSS
* JavaScript

## Purpose

The goal of The Free Everything List is to make useful free resources easier to discover by organizing them in one place.
